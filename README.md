# CivicWatch

CivicWatch is a civic infrastructure transparency platform developed during Cyberathon to improve public accountability in civic issue resolution.

Unlike traditional complaint portals where reports remain hidden, CivicWatch introduces a **public transparency layer** where citizens can report, monitor, and track unresolved civic issues in real time.

The platform focuses on increasing administrative accountability through:
- public issue visibility
- pending-time tracking
- ward performance scoring
- transparent resolution progress

---

# Problem Statement

Many civic complaints remain unresolved due to:
- lack of transparency
- poor public visibility
- weak accountability mechanisms
- absence of measurable performance tracking

Citizens often do not know:
- whether an issue is acknowledged
- how long it has been pending
- whether authorities are actively resolving it

CivicWatch addresses this gap by making civic issue resolution transparent and publicly measurable.

---

# Key Features

## Public Civic Issue Dashboard
- View publicly reported civic problems
- Track issue status in real time
- Monitor unresolved complaints

## Progress-Based Accountability System
- Ward performance visualized using dynamic progress bars
- Resolution percentages create public accountability pressure
- Encourages healthy competition between wards

## Time-Pending Tracking
- Displays how long an issue has remained unresolved
- Creates urgency for authorities to act faster

## Issue Lifecycle Tracking
Issues move through a transparent 4-stage workflow:

```text
Reported → Acknowledged → In Progress → Resolved
```
